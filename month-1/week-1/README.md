# Week 1 — LLM Mental Model

**Days 1–7**

## Learn

- Tokens and tokenization
- Context windows
- Next-token prediction
- Temperature and sampling
- System prompts
- Hallucinations and model limits

## Read and watch

- [Karpathy: Deep Dive into LLMs](https://www.youtube.com/watch?v=7xTGNNLPyMI)
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/en/chapter1/1)

## Build

Create an `llm-playground` script. Test:

- The same prompt with different models
- Short context versus long context
- Temperature 0 versus higher temperature
- JSON output failures
- Hallucination examples

Record the prompt, model, parameters, response, token usage, and observations for each experiment.

## Output

Write a markdown note titled **How LLMs Work in Simple Words** and document five lessons from the experiments.
