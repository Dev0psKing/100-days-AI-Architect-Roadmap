# Code of Conduct

## Our commitment

We are committed to making this project welcoming, respectful, and useful for everyone.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on the work, not the person.
- Welcome different backgrounds and experience levels.
- Assume good intent while addressing mistakes directly.
- Share evidence when recommending technical changes.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate disruption, doxxing, and sharing private information are not acceptable.

Project maintainers may remove contributions or restrict participation when behavior violates this code.

## Reporting

For sensitive or safety-related concerns, contact the repository owner privately through GitHub rather than opening a public issue.
