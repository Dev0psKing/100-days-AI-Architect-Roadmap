## Build

Create automated evaluations for:

- Retrieval correctness
- Answer groundedness
- Citation quality
- Tool selection
- Refusal behavior
- Latency
- Token cost

Run the suite against a known baseline. Store results so future changes can be compared rather than judged by intuition.
