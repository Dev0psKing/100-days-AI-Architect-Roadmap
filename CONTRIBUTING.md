# Contributing

Thank you for helping improve the 100-Day AI Architect Roadmap.

## Good contributions

- Correct broken, outdated, or misleading content.
- Improve clarity, structure, accessibility, or navigation.
- Add high-quality learning resources that match a specific week.
- Add practical exercises, evaluation criteria, or architecture guidance.
- Report gaps, unclear tasks, and broken links.

Keep the roadmap focused on the single capstone project and prefer practical, evidence-based material over tool hype.

## Workflow

1. Open an issue for significant changes or new roadmap sections.
2. Fork the repository and create a focused branch.
3. Make the smallest complete change that solves the issue.
4. Preserve the existing Markdown structure and navigation.
5. Check every link and render Mermaid diagrams before submitting.
6. Open a pull request describing what changed and why.

## Pull requests

Please include:

- A clear summary of the change.
- The relevant week or section.
- Links tested or updated.
- Screenshots when changing rendered diagrams or layout.
- Any limitations or follow-up work.

Do not include secrets, private data, or copyrighted material that you do not have permission to redistribute.
