# Week 4 — Security and Guardrails

**Days 82–84, followed by launch preparation on Days 85–90**

## Learn

- Prompt injection
- Data leakage
- Insecure output handling
- Excessive agency
- Tool abuse

## Read

- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)
- [OpenAI Safety Best Practices](https://platform.openai.com/docs/guides/safety-best-practices)

## Build

Add:

- Prompt injection test set
- Tool allowlist
- Confirmation before write actions
- Context isolation
- Secret redaction
- Safe fallback response
- Rate limiting
- Audit logs

## Launch preparation

During Days 85–90, fix release-blocking issues, run the full evaluation suite, verify deployment, and prepare the final case-study assets.

## Output

An application that is harder to break and safer to demo, with documented threats, mitigations, and known limitations.
